# VMware SOC Home Lab

## Project Overview

This project documents the cybersecurity home lab I built using VMware Fusion on my MacBook Pro.

The lab allows me to safely practice SOC (Security Operations Center) skills, operating system administration, virtualization, and security monitoring without affecting my main computer.

---

## Project Goal

Build a virtual cybersecurity lab for learning and practicing SOC Analyst skills.
